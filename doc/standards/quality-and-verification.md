# Quality & Verification

- Treat correctness, readability, and maintainability as parts of the same outcome.
- Follow the project's existing formatting, linting, typing, and testing standards.
- Test meaningful behavior and important edge cases rather than implementation details.
- Validate changes at the appropriate scope and investigate failures instead of bypassing checks.
- Keep documentation, types, tests, and examples consistent with the resulting implementation.
- Report incomplete verification or unresolved limitations clearly.
